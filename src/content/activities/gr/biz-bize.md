Μπιζ Μπιζέ στο Ελληνικό Σπίτι: η πόρτα μας ανοίγει!

Κάθε Σάββατο για δύο ώρες, από τις 14:00 μέχρι τις 16:00, εμείς, τα μέλη του Ελληνικού Σπιτιού, σας περιμένουμε για να μιλήσουμε και να γνωριστούμε, με ζεστό καφέ ή τσάι.

Ελάτε να μάθετε περισσότερα για την Ένωση Ελλήνων Ολλανδίας, τις δράσεις που διοργανώνουμε, πώς μπορεί κάποιος ή κάποια να γίνει μέλος, αλλά και πώς μπορεί να συμμετέχει και να συνεισφέρει σε ό,τι όμορφο δημιουργούμε μαζί!
